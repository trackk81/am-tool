# AM Tool

AI 이미지 생성, 작업 프로젝트와 레퍼런스 보드를 관리하는 Windows 앱입니다.

## 다운로드

[최신 버전 다운로드](https://github.com/trackk81/am-tool/releases/latest)에서 `amtool-2.6.32-Windows-x64.zip`을 내려받으세요.

1. 실행 중인 AM Tool을 종료합니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. 폴더 안의 `amtool.exe`를 실행합니다. EXE만 따로 복사하지 마세요.

기존 레퍼런스 보드와 연결된 이미지 폴더는 함께 보관하세요.

## 비용

AM Tool은 무료로 사용할 수 있습니다. 외부 AI 제공사를 사용하는 생성 요청에는 해당 제공사의 API 요금이 별도로 발생할 수 있습니다.

## 2.6.32 변경사항

- Gemini 직접 요청에 `store: false`를 명시해 요청 로그 저장을 끄도록 설정했습니다. 이미지 생성, 클라우드 번역, API 연결 확인에 적용합니다.
- 레퍼런스 보드에서 이미지 한 장을 복사하면 외부 앱에 이미지로 붙여넣을 수 있도록 개선했습니다. 보드 식별 문자열이 일반 텍스트로 붙여넣어지는 문제를 수정했습니다.
- 보드 내부 항목 복사와 그룹 복사를 유지했습니다.
- 2.6.31의 아이콘 및 연결 문서 표시 수정사항을 포함합니다.

## 참고

현재 Windows 배포본에는 코드 서명이 없습니다. 내려받은 ZIP의 SHA-256을 릴리스의 `SHA256SUMS.txt`와 비교할 수 있습니다.

외부 붙여넣기는 대상 프로그램이 이미지 붙여넣기를 지원해야 합니다. 여러 항목을 하나의 이미지로 합성해 복사하는 기능은 포함하지 않습니다.

## 문제 제보
